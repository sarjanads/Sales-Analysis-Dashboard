# Sales Analysis Dashboard

This is an interactive Excel dashboard project created using Microsoft Excel.

## Features
- Revenue Analysis
- KPI Cards
- Monthly Trends
- Top Products
- Top Cities
- Interactive Slicers

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers

## Files Included
- Dashboard Excel file
- Raw dataset file
- Dashboard screenshot
