# 📊 FNP Sales Analysis Dashboard (Excel)

## 🎯 Project Objective
The objective of this project is to analyze FNP sales data and build an interactive Excel dashboard to track revenue performance, customer behavior, and product trends. This helps in identifying key business drivers and supporting data-driven decision-making.

---

## 📊 Dashboard Overview
This dashboard provides insights into:
- Revenue performance trends
- Product-wise sales analysis
- Customer purchase behavior
- Order distribution across cities
- Monthly sales performance

---

## 📈 Key Features
- KPI Cards (Total Revenue, Orders, Average Order Value, Profit)  
- Monthly Revenue Trend Analysis  
- Top-Selling Products  
- Top Cities by Orders  
- Customer Purchase Analysis  
- Interactive Slicers (Region, Category, Time Period)  

---

## 💡 Key Business Insights
- Identified top-performing products contributing most to revenue  
- Analyzed monthly sales trends to understand seasonal patterns  
- Compared customer purchasing behavior across different cities  
- Highlighted key revenue-driving products and categories  
- Discovered high-performing and low-performing regions
